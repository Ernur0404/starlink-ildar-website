# Starlink KZ — лендинг

Статический сайт: HTML + CSS + JS, без сборки и без Node.js.
Чтобы посмотреть — просто откройте `index.html` двойным кликом.
Чтобы опубликовать — залейте **всю папку целиком** на хостинг.

---

## Что где лежит

```
index.html            ← казахская версия (главная страница)
ru.html               ← русская версия
assets/
  css/style.css       ← все стили сайта
  js/main.js          ← контакты, форма, маска телефона, меню
  img/                ← картинки (см. assets/img/README.txt)
    favicon.svg       ← иконка во вкладке браузера
README.md             ← этот файл
```

## 1. Как поменять контакты

Все контакты лежат **в одном месте** — в начале файла `assets/js/main.js`:

```js
var CONTACTS = {
  whatsapp: '77058896815',              // номер WhatsApp, только цифры, без + и пробелов
  phone:    '+7 705 889 6815',          // как телефон показывается на сайте
  company:  'ЖК «___»',                 // ЗАГЛУШКА — впишите название
  address:  '___ қаласы, ___ көшесі',   // ЗАГЛУШКА — впишите адрес
  email:    'info@example.kz'           // ЗАГЛУШКА — впишите почту
};
```

Поменяли здесь — поменялось **сразу на обеих страницах**, в футере и во всех
кнопках WhatsApp. Больше нигде номер править не нужно.

> ⚠️ `whatsapp` пишется **без плюса и без пробелов**: `77058896815`, а не `+7 705 889 6815`.

### Что осталось заполнить
- [ ] Название компании / ТОО / ЖК
- [ ] Юридический или фактический адрес
- [ ] E-mail
- [ ] Логотип (сейчас текстовый «STARLINK KZ»)

## 2. Как поменять текст и цены

Текст лежит прямо в HTML — открывайте файл в любом редакторе (VS Code, Notepad++)
и правьте между тегами.

**Цены** ищите по слову `plan__price`:

```html
<div class="plan__price">
  <b>350 000 ₸</b>
  <i>Құрылғының бағасы</i>
</div>
```

Меняете цену в `index.html` — **не забудьте поменять и в `ru.html`**.
Это две отдельные страницы, они не связаны автоматически.

## 3. Фото первого экрана

Установлены два фото — сайт сам выбирает нужное по ширине экрана:

| Файл | Где показывается | Размер |
|---|---|---|
| `assets/img/hero.jpg` | компьютер (шире 760px) | 1920×1244, 299 КБ |
| `assets/img/hero-mobile.jpg` | телефон (уже 760px) | 940×1670, 291 КБ |

Горизонтальное фото на телефоне обрезалось бы до неузнаваемости — поэтому
для мобильных отдельная вертикальная версия.

**Чтобы поменять** — положите свой файл с тем же именем, код править не нужно.
Текст на компьютере лежит слева (значит, левая часть фото должна быть тёмной),
а на телефоне — сверху (значит, сверху должно быть небо).

> ⚠️ **Не заливайте фото прямо с телефона или из нейросети.** Исходники этих
> картинок весили 6.2 МБ и 2.3 МБ — сайт грузился бы полминуты. Сжали до ~300 КБ,
> качество на глаз не изменилось. Держитесь в пределах 400 КБ; сжать бесплатно —
> на [squoosh.app](https://squoosh.app) или [tinypng.com](https://tinypng.com).

Если файл удалить, сайт не сломается — покажется тёмно-синий градиент.
Подробнее — в `assets/img/README.txt`.

## 4. Как работают заявки

Формы **не отправляют письма и ничего не сохраняют**. Логика такая:

1. Посетитель заполняет Имя / Телефон / Город
2. Нажимает «Отправить заявку»
3. Открывается WhatsApp с уже готовым текстом:

```
Здравствуйте! Оставляю заявку на Starlink.

Имя: Ерлан
Телефон: +7 (777) 123-45-67
Город: Шымкент
```

4. Посетителю остаётся нажать «Отправить» в самом WhatsApp

Кнопки у комплектов шлют свой текст — менеджер сразу видит, спрашивают про
Standard или про Mini.

**Важно:** заявка засчитывается только когда человек нажал «Отправить» в WhatsApp.
Если нужно, чтобы заявки падали автоматически и ничего не терялось — можно
подключить Telegram-бота, тогда заявка придёт даже если человек передумал в WhatsApp.

## 5. Языки

Переключатель `ҚАЗ / РУС` в шапке — это обычная ссылка между двумя файлами:

| Страница | Файл | Язык |
|---|---|---|
| Главная | `index.html` | казахский |
| Русская | `ru.html` | русский |

Сделано двумя файлами специально: обе версии видит Google, обе работают
без JavaScript, и текст правится прямо в HTML.

Язык страницы задан в теге `<html lang="kk">` / `<html lang="ru">` — от него
зависит, на каком языке уйдёт сообщение в WhatsApp. **Не меняйте `lang`.**

---

## 6. Как опубликовать

**Вариант А — обычный хостинг (beget, ps.kz, hoster.kz):**
залейте содержимое папки в корень сайта (`public_html` или `www`) по FTP.

**Вариант Б — бесплатно:** [netlify.com](https://app.netlify.com/drop) —
перетащите папку в окно браузера, сайт поднимется за 10 секунд.

Никакой сборки, `npm install` и настройки сервера не нужно — это обычная статика.

## Технические детали

- Шрифт **Inter** с Google Fonts — поддерживает казахские буквы ә ғ қ ң ө ұ ү һ і
- Иконки — SVG-спрайт внутри HTML, внешних библиотек нет
- Адаптив: 3 брейкпойнта (1280 / 1100 / 900 / 640 px), на мобильных — бургер-меню
- Маска телефона понимает `8705…`, `+7 705…`, `705…` — приводит всё к `+7 (705) …`
- Есть SEO-разметка: title, description, OG-теги, `hreflang` между версиями
- Учитывается `prefers-reduced-motion` — анимации отключаются для тех,
  у кого в системе выключены эффекты
